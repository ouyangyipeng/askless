EXPLORE → DECIDE → VERIFYPYTHON 
from pathlib import Path
from askless import explore
from askless.orders import (
    ORDER_DECISIONS, load_orders, preview_orders,
)

data = load_orders(Path("examples/orders.json"))
run = explore(
    adapter="order-summary/v1",
    inputs=data,
    decisions=ORDER_DECISIONS,
    preview=preview_orders,
)

# Collect the remaining choices from the user.
result = run.resolve(
    {"duplicates": "last", "cancelled": "exclude"},
    inputs=data,
)
print(result.output["total"])  # 120.00

v0.2 adds a Python SDK, a runnable order-data agent, and portable HTML/JSON reports. The contact workbench remains available. Your preview defines the observable outcome; equality covers that complete declared result on the current input.

Previews run trusted application code in your process. The SDK bounds combinations and stored results; your application owns callback execution time and external side effects. General coding-agent integrations and measured human attention savings remain open work.
